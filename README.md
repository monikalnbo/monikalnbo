## lnbo

**一个人 + 一排 AI Agent，就是一支军队。**

白天指挥 Agent 写代码、打包、发布；晚上它们替我盯服务器。
从拼多多仓储系统到多语言 IDE，从 MCP 工具链到 Electron 三端分发——
想法到成品，往往只隔一个 prompt。
